Formula sheet builder

Every built-in formula has been checked and has a name, what its symbols mean, and a worked example; edit any cell and it saves. Type a new formula using plain text — / for a fraction, ^ for an exponent, _ for a subscript (e.g. "1/2 mv^2", "H_2O"). For a fraction with more than one term on top or bottom, wrap it in brackets, e.g. "(Gm1m2)/(r^2)". You can also write sqrt(...) for a root, Greek letters by name (pi, theta, Delta, lambda), charges like "SO4^2-", and -> for an arrow. It's formatted the moment you add it, right here in the browser — no lookups, nothing sent anywhere.
