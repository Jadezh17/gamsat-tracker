Daily maths sheet

A fresh no-calculator set every day across the eight maths topics: arithmetic, proportion, algebra, logs, graphs, units, trigonometry and probability. Each topic has two core questions, then two two-step GAMSAT-style questions where you have to convert, rearrange or read a graph before applying the idea (any formula needed is given). Section 3 fundamentals check

For every topic on your Section 3 checklist (15 biology, 12 chemistry, 10 physics, 5 maths): a short theory question, then a GAMSAT-style multiple-choice question that applies the same idea to an unfamiliar stem. Each topic rotates through its question sets day by day, so you never get the same one two days running. Stuck? Hit Theory card on any question to flip it and see all the theory you need for it.

Formula sheet builder

Every built-in formula has been checked and has a name, what its symbols mean, and a worked example; edit any cell and it saves. Type a new formula using plain text — / for a fraction, ^ for an exponent, _ for a subscript (e.g. "1/2 mv^2", "H_2O"). For a fraction with more than one term on top or bottom, wrap it in brackets, e.g. "(Gm1m2)/(r^2)". You can also write sqrt(...) for a root, Greek letters by name (pi, theta, Delta, lambda), charges like "SO4^2-", and -> for an arrow. It's formatted the moment you add it, right here in the browser — no lookups, nothing sent anywhere.

Sync with GitHub

Use the same data in every browser — your phone, your laptop, even a private or incognito window — by saving it to a secret gist on your GitHub account. Changes upload automatically a few seconds after you make them.
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Generate new token (classic). The link opens it with the right box ticked.
  2. Leave only gist ticked, pick an expiry, click Generate token and copy it.
  3. Paste it here and click Connect. Use the same token in each browser.
